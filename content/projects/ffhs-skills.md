Built for my fellow students at FFHS; the skills work in German. One skill reads a module plan and builds the whole semester's Obsidian vault: folders, a start page, the schedule, a textbook chapter map and note templates. The other takes a class preparation assignment plus the textbook PDF and writes concept notes, the preparation note and a running Python cheat sheet.
